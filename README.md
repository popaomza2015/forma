# FORMA — Brass Tape Fitness Web App

> **FORMA** เป็นเว็บแอปติดตามสรีระและสมดุลพลังงานสำหรับมือถือ (Mobile-only Web App) ที่สร้างด้วย **Next.js 14 + Tailwind CSS + TypeScript** 
> ภายใต้คอนเซปต์ **"Brass Tape"** (สมุดบันทึกกระดาษสีอุ่น ตัวเลขตารางคมชัด และเส้นวัดทองเหลือง)
> ไม่ใช่นีออนยิม ปราศจากเสียงรบกวน ไม่มีระบบสมัครสมาชิก และเก็บข้อมูลทั้งหมดไว้ในเครื่องผ่าน `localStorage`

---

## จุดเด่นและแนวคิด (Concept & Features)

* **ความงามแบบ Brass Tape**: โทนสีกระดาษอบอุ่น (`#F3F0EA`, `#FBF9F5`), หมึกชาร์โคลลึก (`#1C1B19`), เส้นสายทองเหลือง (`#A6844A`) และสีแคลอรี่เทอราคอตตา (`#C4623A`)
* **ตัวเลข Tabular Numbers คมชัด**: ใช้ฟอนต์ **IBM Plex Sans Thai** พร้อมเปิดใช้ฟีเจอร์ `tabular-nums` สำหรับตัวเลขตารางทั้งหมด
* **ปราศจากความกดดัน**: ไม่มีชาร์ตโดนัท ไม่มีคอนเฟตติเฉลิมฉลองเกินจริง และไม่มีข้อความ body-shaming
* **4 แถบหลัก + Profile Sheet**:
  1. **วันนี้ (Today)**: แสดงวันภาษาไทย, แคลอรี่เป้าหมาย-ได้รับ-คงเหลือ พร้อมแถบ Linear Track 8px, การ์ดการฝึกประจำวัน, สรุปสัดส่วนรอบเอว/น้ำหนักล่าสุด และปุ่มลัดถ่ายภาพอาหาร/วัดสัดส่วน
  2. **แผน (Plan)**: แผนฝึกซ้อม 7 วันตามกฎโครงสร้าง (3 วัน Full Body / 4 วัน Upper-Lower / 5 วัน PPL+UL) พร้อมการตั้งค่าเซ็ตและเวลาพักตามเป้าหมาย (ลดไขมัน / เพิ่มกล้าม / รักษาสมดุล) รองรับการสลับท่าฝึก (Exercise Swap)
  3. **จาน (Food)**: บันทึกอาหารด้วยกล้อง/ภาพถ่าย หรือพิมพ์ระบุ พร้อมชิปปรับสัดส่วนจาน 0.5 / 1.0 / 1.5 คูณสเกลพลังงานและสารอาหารอัตโนมัติ ติดป้าย "ค่าประมาณ" เสมอ
  4. **สัด (Measure)**: บันทึกสรีระ 8 จุดตามมาตรฐานคงที่ (รอบคอ, รอบอก, รอบเอว, รอบสะโพก, รอบแขนซ้าย, รอบต้นขาซ้าย, ส่วนสูง, น้ำหนัก) พร้อมเกณฑ์อ้างอิงรอบเอวเอเชีย (IDF/WHO) และสูตรประเมินไขมัน U.S. Navy Body Fat
* **Session Player**: เครื่องเล่นการฝึกซ้อมโฟกัสทีละท่าฝึก ปรับน้ำหนัก/ครั้ง บันทึกเซ็ต และตัวนับเวลาพักพร้อมเส้นวัดทองเหลือง
* **Profile Sheet**: เปิดเป็น Bottom Sheet จากมุมขวาบนของ Header เพื่อปรับข้อมูลสรีระและเป้าหมาย โดยคำนวณแคลอรี่ตามสมการ **Mifflin-St Jeor** (ขั้นต่ำ 1,200 kcal) โดยไม่ลบประวัติการฝึกเดิม

## การติดตั้งและเปิดใช้งาน (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รันโหมด Development
npm run dev

# บิลด์สำหรับ Production
npm run build
npm start
```

เปิดใช้งานผ่านเบราว์เซอร์ที่ `http://localhost:3000` (แนะนำให้เปิดใช้งานในโหมด Mobile View หรือบนสมาร์ตโฟน)
